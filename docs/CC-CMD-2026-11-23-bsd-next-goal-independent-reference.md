## The rule, fixed before the run

**Step A, source against source (no ledger).** For every match in R2 whose archive rows give exactly one distinct ESPN id (E2), compare ESPN's goal list with FIELD's BSD capture: same number of goals, same order of sides, same minutes within 1. Counts only: matches compared, identical, different in number, in order, in minute.

**Step B, the ledger against ESPN.** For each of the 372-class calls (the census's gradeable calls, taken at run time) on a match whose archive rows (E2) give exactly one distinct `espn_event_id` and whose ESPN final score equals the capture's (that id is the ESPN match; no name join is run here): k = the total of `score_at_call`; ESPN's resolving goal is its (k + 1)th goal in clock order; ESPN's side is that goal's scoring side (an own goal credited to the beneficiary, per E3); FIELD-independent verdict is `hit` if that side equals the call's `side`, else `miss`; the call **agrees** when the verdict equals the ledger's `outcome`. The join must also hold: ESPN's score before that goal equals `score_at_call`, else not applicable. Every call lands in agree, disagree or one named not-applicable reason, including E2's named reasons (`eflchamp: no archive rows`, `ucl or europa: archive rows, outside the join's sports`, `before 2026-10-24, no joined row that day`, `other unjoined`, `rows carry no ESPN id`, `rows conflict on the ESPN id`, `final score differs`) and "the match has no ESPN timeline". Agree and disagree are tallied by league, by whether ESPN and BSD's capture agree on that goal (from step A), and by distance between ESPN's goal minute and the ledger's `resolved_minute`.
A disagreement is a count and a named reason, never explained away (Rule 77). No probability is graded.
