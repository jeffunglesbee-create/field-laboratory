## The problem this types away

Six BDB files currently serve **2022** data under **`targetYear: 2026`**. The
values are well-formed, correctly named, plausible in magnitude, and four years
stale. Nothing in any render path complains, and two of those files
(`bdb_separation`, `bdb_route_entropy`) already have client consumers.

The two vintages also **collide on field names**: `bdb_time_to_throw` (2022) and
`ngs-passing` (2026) both carry `avgTimeToThrow`. Joining them mixes seasons
silently, with no error and a plausible result.

A comment cannot fix this and a code review will not catch it every time. **A
data flow cannot be grepped. It can be typed** — this repo's own thesis, and the
`SealedDrama` / `AmnestyZone` gate is the precedent.

## The design

Vintage travels **inside** the value, not beside it:

```fsharp
[<Measure>] type season

/// Where a number came from in time. Private cases: only the decoder mints one.
type Vintage =
    private
    | Archive of int<season>
    | Current of int<season>

/// A value that cannot be separated from the season it describes.
/// Private constructor — there is no way to build one without a Vintage.
type Tracked<'T> = private Tracked of value: 'T * vintage: Vintage
```

Three rules make it hold:

1. **The decoder is the only mint.** It reads `season` from the payload envelope
   and stamps it. Nothing else can construct a `Tracked`.
2. **A missing `season` fails the decode.** It must not default to the current
   year. Absence reading as "current" is precisely the defect the six existing
   files have, and the default is what makes it invisible.
3. **Render takes the season being displayed** and refuses a mismatch:

```fsharp
type VintageMismatch = { displaying: int<season>; value: Vintage }

val render :
    displaySeason: int<season> -> Tracked<'T> -> Result<Svg, VintageMismatch>
```

There is no unsafe unwrap, no `ToString`, and no accessor that returns the bare
value to a caller that has not supplied a season. A 2022 number reaching a 2026
card is a **compile error** where the call site is static, and a `Result` the
caller must handle where it is not.

next step, not a rewrite.
