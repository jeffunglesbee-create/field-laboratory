# cloned sibling` — and reporting it honestly is where it stopped. A line of
# prose on an otherwise-green run costs nothing, so it never got fixed, and
# three-state discipline (`true` / `false` / `null`) turned into two states plus
# a shrug.
#
# `null` is now a NUMBER. Every gap the run finds must be declared here with the
# corpus that would close it. A new gap fails the check — the same ratchet shape
# as docs/chrome-inventory.txt in jubilant-bassoon and docs/exposed-secrets.sha256
# here. A gap that CLOSES also fails, until its line is deleted in the commit
# that closed it: an entry nobody removes is how a ledger becomes decoration.
#
# The `needs` column is not a wish. It names a fixture that can actually be
# built, because an unbuildable requirement is the same shrug in a longer form.
