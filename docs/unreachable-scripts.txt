# serves" — 12 blocking assertions. A new render check was assigned to the same
# key without checking whether it existed. The step kept its name, kept passing,
# and started measuring something else; sport-registry-check.mjs became
# referenced by nothing. Nothing caught it: unused-check.mjs was the obvious
# candidate and it checks F# public values, confirmed by running it against the
# clobbered tree, where it reported 1/1 PASS.
#
# A line here is a claim that the file is deliberately not wired. Delete the line
# in the commit that wires it.
