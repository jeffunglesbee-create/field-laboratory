7. FOUND WHILE PROVING IT
-------------------------

a. The exit budget is pinned twice. docs/early-exit-budget.txt holds 63, and the mutation entry `exit-budget-loose` in scripts/mutation-check.mjs carries `find: "63"` on that file, so any change of the budget leaves the entry's anchor stale. The hook already refuses a budget-only edit for that reason (C5). A legitimate change, an early exit converted or one added on purpose, moves both files in one commit, and the check's own message for a loose budget ("lower the budget to N") names only the first. Nothing is changed here (TOUCH-ONLY-A). The next session that edits the budget will meet the STALE line; this paragraph is where it is explained.

b. Two figures in earlier documents read differently today (section 6). They are not corrected here: docs/GATE-TIMING.md is a dated measurement, and the F1 row is edited only to say the row is built.


8. WHAT THIS DOES NOT ESTABLISH
------------------------------

- The line has not refused a real commit in a live session. The five cases replay history in scratch worktrees, with the hook text from the patch. Unobserved. Read it when a session's commit trips it: the hook prints `early report exits:    N  (ratchet, budget 63)` and then `FAIL  early report exits do not grow`, and the commit does not exist.
- The hook runs only where core.hooksPath is .githooks. scripts/install_pkgs.sh sets it in cloud sessions; a local machine opts in, as the hook's own header says. verify.yml still runs the check and is unchanged, so a session without the hook is caught on the runner, as 77647dc1 was.
- `git commit --no-verify` skips the hook, and so this line.
- The cases cover one tree with a 64th early exit, the tree that fixed it, one clean tree and one budget edit. They are not every way the check can fail; its 22 clauses and its mutation entries are what cover that.
- The scratch worktrees use the main tree's installed node_modules after the package files are shown identical. A fresh session's own install was not exercised.
- The timings are one container on one evening.
