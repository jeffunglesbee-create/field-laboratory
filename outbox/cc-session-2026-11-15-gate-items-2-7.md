## Item 4: `scripts/run-steps.mjs` counts the skips behind the failing step

`stepSummary` counted every skipped step as "behind" the failing one. With the Chromium gate's final step the failing step is the LAST one, so the twenty browser checks that did not run were reported as "did not run behind it" when they ran (were skipped) before it.
